# Masthead

공식 배너는 사용자가 대한민국 정부 조직 및 관련 기관에서 운영 및 관리하는 디지털 정부서비스임을 식별할 수 있도록 제공하는 정보 배너이다.

## Import

`import { Masthead } from 'krds-react'`

## Props

| Prop | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `text` | string | 예 | — |
| `className` | string | 아니오 | — |

## 사용 예시

### Default

```tsx
{
  args: {
    text: '이 누리집은 대한민국 공식 전자정부 누리집입니다.'
  }
}
```
