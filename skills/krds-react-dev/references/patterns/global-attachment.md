# 첨부파일

## 개요

첨부파일은 게시물, 본문 등에 제공되는 다운로드 가능한 콘텐츠를 의미한다.

## 구조

1. **파일 이름** — 파일 이름 텍스트(인라인 링크는 파일 이름+파일 정보가 다운로드 링크로 사용될 수 있음)
2. **파일 정보** — 파일 유형, 파일 크기, 페이지 수 정보
3. **다운로드 링크**
4. **미리 보기 링크** — 다운로드 없이 새 탭에서 미리보기
5. **컨테이너** — 다른 콘텐츠와 구분하는 테두리
6. **아이콘(선택)** — 첨부파일 형식을 안내하는 이미지(다운로드 링크로도 사용 가능)

## 유형

| 유형 | 설명 |
| --- | --- |
| 인라인 링크 | 본문 텍스트 사이에 파일 이름·파일 정보 텍스트로 제공되는 링크 |
| 목록 링크 | 본문에서 단독으로 제공되며 컨테이너로 주변 콘텐츠와 분리, 다운로드 링크와 미리 보기 링크가 별도 제공. 주로 본문 관련 상세 문서 제공에 사용 |
| 아이콘 링크 | 아이콘 형태로 축약. 주로 구조화 목록, 표에서 파일 다운로드에 사용 |

## 사용성 가이드라인

- **링크가 파일 다운로드를 유발할 수 있음을 사용자에게 사전에 안내한다.** 첨부파일 링크 주변에 '다운로드' 텍스트를 포함한 설명을 제공하거나 다운로드 링크를 제공해, 실행 시 발생할 동작을 사용자가 예측할 수 있어야 한다.
- **파일의 크기와 형식 정보를 표시한다.** 인라인 링크·목록 링크는 파일 이름 우측에 '[파일 유형, 파일 크기]'를 제공한다. 파일 크기는 KB, MB, GB 단위로 표시한다.
- **인라인 링크 유형의 첨부파일 텍스트는 주변 콘텐츠와 비슷한 크기로 제공한다.** 본문 내 링크 텍스트 크기는 해당 줄/단락의 글자 크기와 일치해야 한다.

## 접근성 가이드라인

- **첨부파일 아이콘 이미지에 적절한 대체 텍스트를 제공한다.** 아이콘 이미지로 표시한 경우 대체 텍스트는 정확한 첨부파일명으로 제공해야 한다. 관련: KWCAG 2.2 적절한 대체 텍스트 제공/적절한 링크 텍스트, WCAG 2.1 Non-text Content(A)/Headings and Labels(AA).
- **첨부파일은 스크린 리더가 접근할 수 있는 형식으로 제공한다.** 본문은 텍스트 형식으로 구성하고, 이미지에는 각 문서 형식 표준이 지원하는 방식으로 대체 텍스트를 제공해야 한다.

## 관련 KRDS 컴포넌트

| 컴포넌트 | 비고 |
| --- | --- |
| Link | 인라인 링크, 목록 링크의 다운로드/미리보기 링크 |
| StructuredList | 목록 링크·아이콘 링크 형태로 여러 첨부파일을 나열할 때 |
| Table | 아이콘 링크 형태로 표 내부에서 파일을 다운로드할 때 |

이 패턴은 파일 다운로드(표시) 흐름을 다루며, 업로드 흐름은 다루지 않는다 — 사용자가 파일을 업로드하는 입력폼에는 별도로 `FileUpload` 컴포넌트를 사용한다(이 문서의 대상은 아님).
