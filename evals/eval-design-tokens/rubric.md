# eval-design-tokens — 채점표

| 항목 | 필수/권장 | 통과 기준 | 채점 |
| --- | --- | --- | --- |
| 매직넘버 체계로 답변 | 필수 | 답변이 명도 대비를 매직넘버(색상 팔레트 명도 단계 숫자)와 대비율 쌍으로 설명한다 — 최소 "매직넘버 50 = 4.5:1(본문 텍스트 최소 대비)"을 정확히 언급한다. 40=3:1, 70=7:1, 90=15:1 중 관련 있는 값을 추가로 인용하면 더 좋다 | ☐ |
| 코드 작성 안 함 | 필수 | 답변에 JSX/TSX/CSS 코드 블록이나 `var(--krds-...)` 실제 구현 코드가 없다. 순수 설명(색상 이름·매직넘버·대비율 텍스트)만으로 구성된다 | ☐ |
| 근거가 스킬 데이터와 일치 | 필수 | 제시한 숫자·규칙이 `krds-design` SKILL.md의 색상 체계 절과 모순되지 않는다(예: 배경 primary + 텍스트는 흰색 계열 또는 매우 어두운 계열 중 4.5:1 이상을 만족하는 조합을 근거와 함께 제시, System 색상과 혼동하지 않음) | ☐ |
| 60-30-10 규칙 또는 Primary 역할 코멘트 | 권장 | Primary는 "주요 상호작용 요소"에 쓰이는 색으로 전체 화면의 10% 비중이 기본이라는 점, 또는 배경 전체를 Primary로 채우는 것이 KRDS 색상 역할 정의와 다소 어긋날 수 있다는 코멘트를 포함한다 | ☐ |
| 선명한 화면 모드(고대비) 언급 | 권장 | 기본 모드 기준 답변에 더해, 선명한 화면 모드에서는 대비 기준이 더 엄격해진다는 점(헤딩·레이블류 기준 4.5:1→7:1 등, `style_09.md` 근거)을 부가 설명으로 언급한다 | ☐ |
| System 색상과 구분 | 권장 | "공지"라는 표현 때문에 Info/System 색상과 혼동하지 않고, 질문이 명시한 대로 Primary 계열 배경이라는 전제를 유지하며 답한다(필요하면 "공지 성격상 System-Info 색상이 더 적합할 수도 있다"는 대안 제시는 허용되나 반드시 그 경우도 매직넘버 근거를 댄다) | ☐ |

## 통과 기준

필수 3항목 100% + 권장 3항목 중 70%(2/3) 이상.

## 정답 근거 (참조해야 할 스킬 파일)

- `skills/krds-design/SKILL.md` — "색상 체계" 절: 매직넘버 표(40/3:1, 50/4.5:1, 70/7:1, 90/15:1), 60-30-10 규칙, 색상 역할(Primary/Secondary/Accent/Graphic/System), 선명한 화면 모드 전환 원리
