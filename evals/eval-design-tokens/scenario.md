# eval-design-tokens — 시나리오

## 대상 스킬

`skills/krds-design`

## 전제 조건

1. `krds-design` 스킬이 설치된 Claude Code 세션에서 실행한다.
2. 이 평가는 코드 작성 요청이 아니라 **디자인 질의응답**이다 — 세션이 코드를 쓰지 않고 답변으로 끝내는지 자체가 채점 대상이다.
3. 별도로 표준형/확장형 스타일 여부를 지정하지 않는다. 세션이 필요하면 되물어도 되고, 일반 원칙(매직넘버 체계)으로 답해도 된다.

## 사용자 프롬프트 (원문)

```
공지 배너 배경을 primary 계열로 하고 싶은데 텍스트 색은 뭘 써야 해? 대비 기준도 알려줘
```

## 관찰 포인트

- 답변이 "매직넘버"(40/50/70/90 ↔ 3:1/4.5:1/7:1/15:1) 체계로 근거를 제시하는가, 아니면 임의의 색상 조합을 추천하는가.
- 배너 텍스트에 요구되는 대비 기준을 정확히 짚는가(본문 텍스트 기준 매직넘버 50=4.5:1이 기본 원칙이고, 강조가 필요하면 70=7:1 이상도 언급 가능).
- 60-30-10 규칙, 색상 역할(Primary는 "가장 주목받는 요소"에 한정) 등 과도하게 배경을 primary로 전면 사용하는 것에 대한 코멘트가 있는가(선택 사항이지만 있으면 가산점).
- 코드(JSX/CSS)를 작성하지 않고 순수 답변으로 끝나는가.
