# 모바일 설정

## 개요

앱 사용 경험 전반을 사용자 주도적으로 제어할 수 있도록 제공하는 관리 허브다. 계정·보안·알림·접근성·언어·데이터·법적 고지 등 정책적/기술적 선택지를 한 곳에 모아, 사용자가 자신의 상황(기기·환경·능력)에 맞게 동작을 조정하고, 위험도가 높은 변경은 충분히 이해·확인하도록 돕는다. 정부기관 APP의 설정은 공공 서비스 특성상 투명성(무엇이, 왜 바뀌는지)과 복구 가능성(되돌리기/초기화)을 최우선으로 한다.

## 구조

1. **제목** — 정보 변경이나 제어하려는 목적에 대한 설명
2. **다음 화면 이동 버튼** — 정보 변경/제어 내용이 많아 다음 화면에 표시해야 하는 경우 사용
3. **토글스위치** — 즉각적인 제어를 목적으로 상태를 전환하는 요소

## 유형

| 유형 | 설명 |
| --- | --- |
| 계정/프로필 설정 | 이름, 연락처 등 계정정보 등록·변경 |
| 보안·알림 등 앱 동작 제어 | 앱 사용에 따른 동작 및 상태 제어 |
| 정보 표시 | 이용약관, 개인정보 처리방침, 버전/빌드 등 앱 사용 정보 표시 |

## 사용성 가이드라인

- **사용자가 변경 결과를 예측할 수 있고 즉시 확인하며 언제든 되돌릴 수 있어야 한다.** 정보 구조는 6~9개의 상위 카테고리로 단순화하고, 위험도와 사용 빈도가 높은 항목을 화면 상단에 배치하며, 기술적이거나 저빈도 항목은 하위 단계로 접어 점진적으로 공개한다. 검색창을 상단에 두고 결과에서 해당 위치로 바로 이동하는 딥링크를 제공하면 재방문·탐색 효율이 높아진다.
- **컨트롤은 목적에 맞게 선택한다.** 상태의 즉시 전환에는 저장 버튼 없이 바로 반영되는 토글 스위치를, 상호배타적 선택에는 라디오 버튼을 사용한다. 독립적인 다중 선택은 체크박스로, 연속값·구간은 범위 슬라이더로, 항목이 많거나 드물게 바꾸는 설정은 검색 가능한 셀렉트로 다룬다. 날짜·시간 같은 특수 입력은 전용 피커를 사용하고, 2~4개 상위 모드 전환은 세그먼트 탭이 적절하다. 파괴적이거나 되돌리기 어려운 작업(초기화·탈퇴·번호 변경 등)은 단일 버튼 뒤에 재확인 다이얼로그를 두고 반드시 2단계 인증을 거치게 한다.
- **설정 변경은 즉시 적용하며, 간결한 피드백을 제공한다.** 가능하면 즉시 적용하고 스낵바·토스트로 2~3초 안에 간결한 피드백(결과와 후속 행동 1가지만, 예: "푸시 알림이 꺼졌습니다. 되돌리기")을 제공하며 스크린리더로 읽히도록 한다. 여러 필드를 한꺼번에 수정해 서버 저장이 필요한 경우 하단 고정 저장 버튼을 제공하고 입력이 유효할 때만 활성화한다. 실패 시 원인을 짧게 알리고 원상복구·재시도 방법을 함께 안내한다.
- **개인정보와 보안 등 중요정보의 변경은 2단계 인증한다.** 보안·개인정보에 영향을 주는 변경은 생체 인증 또는 비밀번호로 2단계 인증을 요구하고, 변경의 영향·복구 방법·적용 소요 시간을 한 화면에서 요약한다. 계정 삭제·번호 변경처럼 악용 우려가 있는 작업은 일정 시간의 지연 적용과 알림 고지를 포함한다. 최근 설정 변경 이력을 항목·일시·기기 기준으로 열람할 수 있게 하면 사용자 신뢰가 높아진다.
- **네트워크와 권한, 정책에 따른 예외 흐름도 명확해야 한다.** 오프라인에서는 변경을 로컬 큐에 보관한 뒤 연결 시 적용하고, 충돌 시 병합 또는 마지막 적용 기준을 사용자에게 설명한다. OS 권한이 필요한 기능은 앱 내부 토글과 운영체제 권한 스위치를 구분해 안내하고, 필요하면 시스템 설정 이동 버튼을 제공한다. 조직 정책으로 잠긴 항목은 비활성화 사유를 툴팁으로 알려 혼란을 줄인다.

## 관련 KRDS 컴포넌트

이 패턴은 모바일 앱 설정 화면을 대상으로 서술되어 있지만, 원문이 언급하는 컨트롤 유형은 krds-react 웹 컴포넌트와 대응된다.

| 컴포넌트 | 대응 컨트롤 |
| --- | --- |
| ToggleSwitch | 즉시 전환되는 상태(토글 스위치) |
| Radio | 상호배타적 선택 |
| Checkbox | 독립적인 다중 선택 |
| Dropdown | 항목이 많거나 드물게 바꾸는 설정(검색 가능한 셀렉트) |
| Select | 옵션 선택 |
| DateInput | 날짜·시간 특수 입력 |
| Tab | 2~4개 상위 모드 전환(세그먼트 탭) |
| Modal | 파괴적/되돌리기 어려운 작업의 재확인 다이얼로그 |
| Tooltip | 조직 정책으로 잠긴 항목의 비활성화 사유 안내 |
| Button | 저장 버튼, 시스템 설정 이동 버튼 |

원문의 슬라이더(범위 슬라이더), 스낵바/토스트 피드백은 `references/components/README.md`의 39종 컴포넌트에 직접 대응하는 항목이 없다 — 커스텀 구현 시 KRDS 토큰(`references/tokens.md`)을 사용해 시각적 일관성을 유지한다.
