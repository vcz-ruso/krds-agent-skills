# 상세 정보 확인

## 개요

상세 정보는 특정한 주제에 관한 정보를 제공하는 패턴으로, 효과적인 정보 전달을 위해 텍스트 이외에 다양한 시각적 요소들이 활용된다. 사용자들은 콘텐츠 목록에서 콘텐츠 제목이나 요약 정보를 포함한 링크를 통해 상세 정보에 접근하기 때문에, 사용자가 예상하는 정보를 명확하고 간결하게 전달할 수 있어야 한다.

## 구조

1. **제목** — 본문 전체에 대한 제목
2. **요약 정보** — 본문의 주요 내용을 요약하는 2~3줄 텍스트
3. **상세 정보** — 상세 정보를 전달하는 콘텐츠 섹션(본문)
4. **부가 정보** — 본문 이해를 돕는 콘텐츠 섹션
5. **콘텐츠 변경 이력** — 업로드일, 변경일, 변경 내용 로그
6. **콘텐츠 내 탐색** — 콘텐츠 섹션 구조 파악 및 원하는 섹션 이동 수단
7. **액션 버튼** — 정보 관련 기능 실행 또는 관련 화면 이동

## 유형

| 유형 | 설명 |
| --- | --- |
| 단일 화면 | 모든 상세 정보를 하나의 화면에 제공하고 콘텐츠 탐색 내비게이션으로 주요 단락을 이동. 불가피한 경우를 제외하면 기본적으로 권장되는 레이아웃 |
| 탭 | 단일 화면에 소구하기에 콘텐츠가 지나치게 복잡하거나 섹션 간 성격이 달라 비교 없이 파악해도 되는 경우에 적합 |

## 사용성 가이드라인

- **콘텐츠의 작성자, 출처, 저작권을 표시한다.** 모든 상세 콘텐츠에 표시하여 사용자가 신뢰를 가지고 정보를 이용할 수 있도록 해야 한다.
- **정보 등록, 변경 일자와 변경 내역을 제공한다.** 최초 업로드일부터 모든 변경 내역의 반영 일자와 내역을 헤딩 근처와 본문 마지막에 제공해야 한다.
- **제목은 다른 요소들과 구분되도록 표현한다.** 제목은 현재 위치를 알려주고 본문 내용을 미리 파악하게 돕는다.
- **콘텐츠 요소들 사이의 계층구조를 명확하게 구분한다.** 계층구조가 명확하면 사용자가 중요한 정보를 더 빠르게 처리할 수 있다.
- **문단과 문장은 최대한 간단명료하게 구성한다.**
- **핵심 주제는 첫 문단, 첫 문장에 포함시킨다.** 다음 내용을 예측할 수 있어 내용을 조직화하고 이해하기 쉽다.
- **인포그래픽, 사진, 동영상 등의 콘텐츠를 적절하게 활용한다.** 텍스트에만 의존하는 것보다 효과적으로 전달할 수 있으며 흥미를 유발한다.
- **외부 서비스로 이동하거나 새 창을 실행하는 액션 버튼에 명확한 시각적 단서를 제공한다.** 새 창 열림 아이콘 등으로 현재 이용 맥락을 벗어나지 않도록 한다.
- **화면 너비가 충분한 경우 콘텐츠 내 탐색을 표시하고 본문 우측의 일관된 위치에 고정하여 제공한다.** 목차로 작동하며 클릭 시 연결된 섹션으로 스크롤된다.

## 플랫폼에 대한 고려 사항

**모바일에서 콘텐츠 내 탐색은 제목과 본문 사이에 배치한다.** 화면 너비가 충분하지 않을 때는 특정 위치에 고정하지 않고 제목과 본문 사이에 배치한다. 본문 구조가 복잡해 콘텐츠 내 탐색이 길어지면 디스클로저 같은 확장 가능한 섹션으로 제공할 수 있다.

## 접근성 가이드라인

- **텍스트 콘텐츠와 배경 간 명도 대비를 4.5:1 이상으로 제공한다.** 화면 확대가 가능한 경우 3:1까지 낮출 수 있다. 관련: KWCAG 2.2 텍스트 콘텐츠의 명도 대비, WCAG 2.1 Contrast(Minimum)(AA).
- **텍스트 이외의 콘텐츠에 대체 수단을 제공한다.** 이미지, 음성, 동영상 등에 대체 텍스트·자막 등을 제공해야 한다. 관련: KWCAG 2.2 적절한 대체 텍스트 제공/자막 제공, WCAG 2.1 Non-text Content(A)/Audio-only and Video-only(Prerecorded)(A)/Captions(Prerecorded)(A)/Audio Description or Media Alternative(Prerecorded)(A)/Captions(Live)(AA)/Audio Description(Prerecorded)(AA).
- **멀티미디어 콘텐츠 플레이어는 키보드로 조작할 수 있도록 제공한다.** 재생/정지, 음량, 시간 조절 등 모든 기능이 키보드로 가능해야 한다. 관련: KWCAG 2.2 키보드 사용 보장, WCAG 2.1 Keyboard(A).
- **멀티미디어 콘텐츠가 자동으로 재생되지 않도록 제공한다.** 사용자가 재생을 수행하기 전에는 자동 재생되지 않아야 한다. 관련: KWCAG 2.2 정지 기능 제공/자동 재생 금지, WCAG 2.1 Pause, Stop, Hide(A)/Audio Control(A).
- **가능한 한 이미지 텍스트를 사용하지 않는다.** 이미지 형식의 텍스트는 해상도 손실 없는 확대/축소, 명도 대비·자간 조정이 불가능하다. 심미적 효과나 특정 표현이 필수적인 경우를 제외하고 사용하지 않아야 한다. 관련: WCAG 2.1 Images of Text(AA).
- **시각적으로 표현된 콘텐츠의 구조, 수준을 프로그램적으로 동일하게 제공한다.** 제목, 목록, 표 등 구조화된 정보는 그 의미에 맞는 마크업 요소로 제공해 스크린 리더에서도 동등하게 인지되도록 한다. 관련: KWCAG 2.2 제목 제공, WCAG 2.1 Info and Relationships(A).
