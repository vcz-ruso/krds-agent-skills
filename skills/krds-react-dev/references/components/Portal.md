## Props

| Prop | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `children` | ReactNode | 예 | — |
| `enabled` | boolean | 아니오 | Portal 사용 여부 (기본값: true) |
| `container` | string \| HTMLElement | 아니오 | Portal 컨테이너 ID 또는 HTMLElement |
| `containerClassName` | string | 아니오 | 자동 생성시 컨테이너에 추가할 className |
